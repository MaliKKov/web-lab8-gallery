# Лабораторная работа №8 — Галерея фотографий на PHP и MySQL

**Дисциплина:** WEB-программирование  
**Тема:** «Основы работы с базой данных с использованием языка PHP»

## Цель работы

Изучение принципов взаимодействия PHP с базами данных, закрепление навыков серверного программирования и разработки веб-приложений.

## Описание проекта

PhotoGallery — веб-приложение для загрузки и просмотра фотографий, разработанное с использованием PHP и MySQL.

Приложение состоит из трёх основных страниц:

1. **index.php** — галерея уменьшенных копий фотографий, отсортированных по количеству просмотров.
2. **photo.php** — просмотр оригинальной фотографии с отображением автора и счётчика просмотров.
3. **upload.php** — загрузка фотографии с указанием имени, электронной почты и описания.

## Реализованные возможности

- Загрузка фотографий в форматах JPG, PNG и WEBP.
- Проверка типа и размера загружаемых файлов.
- Автоматическое создание миниатюр с помощью PHP GD.
- Сохранение информации о фотографиях и пользователях в MySQL.
- Подсчёт просмотров фотографий.
- Сортировка галереи по популярности.
- Адаптивное оформление страниц.
- Использование подготовленных SQL-запросов через PDO.

## Использованные технологии

- HTML5
- CSS3
- PHP 8.3

- PDO

- XAMPP

## Структура проекта

```text
Lab8/
├── index.php
├── photo.php
├── upload.php
├── config.php
├── database.sql
├── css/
│   └── styles.css
├── uploads/
└── thumbs/
```

Папки `uploads` и `thumbs` предназначены для хранения оригинальных фотографий и их уменьшенных копий. Они создаются локально и не содержат файлов в репозитории.

## База данных

Используется база данных `lab8_gallery`, содержащая две связанные таблицы:

- **users** — информация о пользователях, загрузивших фотографии.
- **photos** — информация о фотографиях, их файлах, авторах и количестве просмотров.

Связь осуществляется через внешний ключ `photos.user_id`.

## Запуск проекта

1. Установить XAMPP с Apache, PHP, MySQL и расширением GD.
2. Скопировать проект в `C:\xampp\htdocs\Lab8`.
3. Создать пустые папки `uploads` и `thumbs`, если они отсутствуют.
4. Запустить Apache и MySQL в XAMPP Control Panel.
5. Открыть phpMyAdmin по адресу `http://localhost/phpmyadmin/`.
6. Создать базу данных `lab8_gallery`.
7. Импортировать файл `database.sql`.
8. Проверить параметры подключения в `config.php`.
9. Открыть `http://localhost/Lab8/`.
